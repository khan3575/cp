# Library

Reusable, tested snippets. Rules:

1. One algorithm per file, named after the algorithm: `dsu.cpp`, `dijkstra.cpp`.
2. Top of every file: a comment block with **what it does**, **complexity**, and **at least one problem link where you used it**.
3. Code must be copy-pasteable into a solution with zero edits — no `main()`, no `#include <bits/stdc++.h>`.
4. Nothing enters this folder until it has passed on a real judge.
